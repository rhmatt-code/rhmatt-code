### 👨‍💻 Tentang Saya (About Me)

Halo! Saya **Rahmat Abdullah**, seorang **Full-Stack Web & Mobile Developer** yang berbasis di Indonesia. Saya berfokus pada pengembangan aplikasi web yang cepat, responsif, dan terstruktur dengan baik, serta aplikasi mobile lintas platform.

- 🔭 Saat ini sedang fokus mengembangkan ekosistem aplikasi web modern dan layanan backend berperforma tinggi.
- 🌱 Terus mendalami arsitektur sistem, optimasi database, dan manajemen server Linux.
- 💬 Tertarik berdiskusi seputar **Laravel, Go, Flutter, Tailwind CSS**, atau peluang kolaborasi proyek.
